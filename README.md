# Протокол тестирования поиска на сайте Гисметео

Учебный проект по ручному тестированию веб-сайта [gismeteo.ru](https://www.gismeteo.ru). 
Репозиторий содержит тест-кейсы для функционала поиска города и протокол тестирования.

> Проект учебный и не связан с владельцами сайта Гисметео.


## Структура репозитория

```
gismeteo/
├── assets/ 
|   └── ...          # скриншоты и доп файлы к баг-репортам
├── bugs/ 
|   └── ...          # баг-репорты
├── checklists/
    └── ...          # чек-лист
├── reports/
|   └── ...          # Отчет по тестированию 
├── test-cases/
|   └── gismeteo_city_selection_test_cases.md           # Поиск города 
└──  README.md
```
