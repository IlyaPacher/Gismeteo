## Шаги воспроизведения

1. Открыть страницу https://www.gismeteo.ru/
2. Ввести в поле поиска любые 2 буквы
3. Дождаться появления подсказок
4. Нажать на иконку крестика (×) внутри поля.

## Ожидаемый результат
Текст из поля полностью удаляется, выпадающий список подсказок скрыт.

## Фактический результат
Отсутствует иконка крестика (×) внутри поля.
